# Разговорный бот с долговременной памятью

Телеграм-помощник отвечает на сообщения и хранит сведения о каждом пользователе в Pinecone. Поиск и запись идут через `pinecone_manager.py`.

## Состав

| Файл | Назначение |
| --- | --- |
| `telegram_bot.py` | Приём сообщений Telegram и ответы модели OpenAI |
| `pinecone_manager.py` | Чтение и запись векторного или документного индекса Pinecone |
| `requirements.txt` | Зависимости Python |
| `.env.example` | Шаблон настроек без секретов |
| `.env` | Ключи и имя индекса. Файл не публикуют |

## Требования

- Python 3.12
- Индекс Pinecone `vpg05-case-1-a-conversational`
- Ключ OpenAI
- Токен бота от [@BotFather](https://t.me/BotFather)

Текущий индекс документный. Текст лежит в поле `chunk_text`, эмбеддинг считает модель индекса. Метрика — косинусное сходство.

## Установка

В каталоге проекта:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Настройки

Скопируйте шаблон и заполните ключи:

```powershell
Copy-Item .env.example .env
```

`PINECONE_NAMESPACE` можно не задавать: документные операции тогда идут в пространство `__default__`.

`OPENAI_EMBEDDING_MODEL` и `OPENAI_EMBEDDING_DIMENSIONS` нужны методам менеджера, которые сами считают вектор через OpenAI. Размерность должна совпадать с индексом. Бот для этого индекса их не вызывает: текст уходит в `chunk_text`.

## Запуск

```powershell
.\venv\Scripts\python.exe telegram_bot.py
```

В журнале появляется строка `Телеграм-бот запущен.` Остановка — Ctrl+C.

Если в журнале есть `Infinity polling exception` и `RemoteDisconnected`, Telegram закрыл длинный запрос без ответа. Бот спрашивает обновления снова. Если ответы прекратились, перезапустите процесс.

## Как бот запоминает

1. Ищет близкие фрагменты этого пользователя через `search_documents_by_text`.
2. Отвечает моделью `OPENAI_CHAT_MODEL`, подставив найденные факты и последние реплики сеанса.
3. Записывает сообщение через `upsert_schema_documents`.

Граница сходства задаётся в начале `pinecone_manager.py`:

```python
COSINE_SIMILARITY_THRESHOLD = 0.85
```

Допустимый диапазон — от -1 до 1.

- Ниже границы сообщение считается новым и создаёт отдельный слот.
- На границе и выше при том же тексте запись пропускается.
- На границе и выше при другой формулировке обновляется найденный слот.

Чем выше порог, тем чаще похожие сообщения сохраняются как новые. Память разных людей разделена полем `user_id`.

## Команды бота

| Команда | Действие |
| --- | --- |
| `/start` | Приветствие и сохранение имени и идентификатора Telegram |
| `/forget` | Удаление памяти этого пользователя |
| обычный текст | Ответ и запись в долговременную память |

Фото, голос и другие вложения бот не сохраняет.

## Менеджер Pinecone

Класс `PineconeManager` читает ключи из окружения. Ошибки приходят как `PineconeManagerError` с полями `code`, `message` и `details`.

Запись:

- `upsert_vector`, `upsert_vectors` — готовые векторы
- `upsert_document`, `upsert_documents` — текст, эмбеддинг OpenAI, затем вектор
- `remember` — долговременная память с проверкой косинусного сходства
- `upsert_text_records` — текст для индекса со встроенной моделью
- `upsert_schema_documents` — JSON-документы документного индекса

Чтение:

- `query_by_vector`, `query_by_vector_id` — поиск по вектору
- `query_by_text` — текст переводится в вектор через OpenAI
- `search_by_text` — текст считает модель встроенного индекса
- `search_documents_by_vector`, `search_documents_by_text` — поиск по документному индексу
- `fetch_vectors`, `fetch_documents` — чтение по идентификаторам

Удаление и служебные вызовы: `delete_vectors`, `delete_documents`, `describe_stats`, `close`.
